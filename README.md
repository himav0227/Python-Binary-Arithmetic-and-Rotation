# Python Binary Arithmetic and Rotation

## Description
This project contains Python programs for signed binary arithmetic using 8-bit 2's complement and 8-bit rotate operations.

## Programs

1. **Signed Binary Arithmetic:** Performs addition and subtraction using 8-bit 2's complement representation and checks arithmetic overflow.
2. **Rotate Operations:** Performs Rotate Right Without Carry (ROR) and Rotate Right Through Carry (RCR) on an 8-bit binary number.
